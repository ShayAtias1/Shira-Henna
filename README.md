# האתר של שירה · הפרשת חלה וחינה

אתר סטטי. ההזמנה בנויה מאפס, בלי תמונת הזמנה: כרטיס נייר תלת-ממדי (three.js) עם קווים שנמשכים, פריחה, חמסה מובלטת וגדיל משי. האנימציה והגלילה החלקה הן GSAP (ScrollTrigger) ו-Lenis. אם אין WebGL במכשיר, האתר מציג גרסה שטוחה של אותה הזמנה.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז לפתוח http://localhost:5178. השרת בונה מחדש את `site/app.js` בכל שינוי ב-`src/`.

לבנייה חד-פעמית: `npm run build`. את `site/app.js` (כולל three.js, GSAP ו-Lenis) מעלים יחד עם שאר `site/`. בהרצה מקומית שליחת האישור עובדת במצב הדגמה ולא נשמרת בשום מקום.

## מה מגדירים לפני שמעלים

הכול ב-`site/config.js`:

| הגדרה | מה זה |
| --- | --- |
| `RSVP_ENDPOINT` | הכתובת שמקבלת את האישורים: סקריפט Google או webhook של Make (ראו למטה). **חובה**, אחרת האישורים באתר החי לא יישמרו והאורחת תראה הודעת שגיאה. |
| `RSVP_MODE` | `'apps-script'` (ברירת מחדל) לסקריפט Google, או `'webhook'` ל-Make / Zapier / n8n. |
| `WHATSAPP_URL` | לא חובה. קישור וואטסאפ שיוצג אם השליחה נכשלה. |
| `EVENT_DATE` | תאריך האירוע לספירה לאחור. |

### קבלת האישורים ב-Google Sheets (כ-3 דקות)

1. יוצרים Google Sheet חדש.
2. **Extensions ← Apps Script**, מוחקים את הקוד ומדביקים את התוכן של `apps-script/Code.gs`.
3. **Deploy ← New deployment ← Web app**. *Execute as*: Me. *Who has access*: Anyone. מאשרים הרשאות.
4. מעתיקים את כתובת ה-Web app ל-`RSVP_ENDPOINT` ב-`config.js`.

הגיליון `RSVP` נוצר לבד. אורחת שעונה שוב מעדכנת את השורה שלה ולא מוסיפה חדשה.

### קבלת האישורים דרך Make (webhook)

1. ב-Make: **Create a new scenario** ← מודול **Webhooks ← Custom webhook** ← **Add** ← מעתיקים את הכתובת.
2. ב-`config.js`: `RSVP_ENDPOINT` = הכתובת שהועתקה, ו-`RSVP_MODE: 'webhook'`.
3. שולחים אישור אחד מהאתר (או מהרצה מקומית עם הכתובת) ואז לוחצים **Run once** ב-Make כדי שיזהה את השדות: `id`, `name`, `going` (`yes`/`no`), `count`, `website`, `sentAt`.
4. מוסיפים מודול **Google Sheets ← Add a row** ומחברים את השדות לעמודות.
5. ממליצים להוסיף **Filter** בין המודולים: `website` ריק (זה שדה מלכודת לרובוטים, אנשים אמיתיים לא ממלאים אותו).
6. מפעילים את הסצנריו (**Scheduling: Immediately**).

האתר שולח טופס רגיל בלי לקרוא את התשובה של Make (הדפדפן לא מאפשר), ולכן הודעת "נשלח" מוצגת כשהבקשה יצאה. כל שליחה מוסיפה שורה, ואורחת שעונה שוב מקבלת שורה נוספת עם אותו `id`: השורה האחרונה של אותו `id` היא התשובה העדכנית.

## העלאה

מעלים את התיקייה `site/` כמו שהיא לכל אחסון סטטי (Netlify, Cloudflare Pages, GitHub Pages). אחרי שיש כתובת סופית:

- ב-`site/index.html` להחליף `content="og.png"` בכתובת מלאה, למשל `https://הכתובת-שלך/og.png`, אחרת וואטסאפ לא יציג תמונה בתצוגה המקדימה.
- לוודא ש-`shira-henna.ics` מוגש כ-`text/calendar`.

## קבצים

- `site/index.html` – המבנה, וגם הגדרות השכבות הוקטוריות השטוחות (גרסת הגיבוי וטופס האישור).
- `site/styles.css` – העיצוב.
- `src/art.js` – הצורות של ההזמנה (מסגרת, עצים, פריחה, חמסה) במקום אחד.
- `src/hero3d.js`, `src/tassel3d.js` – סצנת ה-3D של ההזמנה והגדיל.
- `src/main.js` – האנימציה, הגלילה, הספירה לאחור וטופס האישור. נבנה ל-`site/app.js`.
- `site/shira-henna.ics` – קובץ להוספה ליומן. שעת הסיום (22:30) הוגדרה כברירת מחדל, ואפשר לשנות.
- `scripts/og.html` – מקור תמונת התצוגה `site/og.png`.
